# Free Digital Signage (Cheat Code Edition)

A simple, zero-cost digital signage setup that turns any Raspberry Pi, old PC, or always-on device into a reliable signage player.

Instead of paying for commercial signage platforms, this method uses:
- Chromium browser in kiosk mode
- A Google Slide (or any public web page) as the content source
- Automatic refresh so updates appear without touching the player

### Why this works well
- Completely free after the one-time hardware cost
- Content is updated from anywhere (just edit the Google Slide or webpage)
- Works offline once the page is loaded
- Easy to maintain — no custom software to update

### What you need
- Raspberry Pi 3/4/5 (or any device that can run Chromium)
- A Google Slide (or self-hosted HTML page)
- ~10 minutes to set up

Ideal for offices, clinics, schools, shops, or community spaces that want professional-looking signage without the subscription fees.
